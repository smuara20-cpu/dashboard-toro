# Tujuan

Component Catalog merupakan daftar resmi seluruh komponen UI pada VENTRA ERP Platform.

Dokumen ini menjadi indeks utama untuk menemukan, mengelompokkan, dan mengidentifikasi setiap komponen dalam Component Library.

---

# Scope

Component Catalog mencakup seluruh kategori komponen:

- Actions
- Inputs
- Navigation
- Display
- Feedback
- Dashboard
