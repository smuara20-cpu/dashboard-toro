# Format Version

Major.Minor

Contoh:

- 1.0
- 1.1
- 2.0

---

# Major Version

Digunakan apabila terjadi perubahan besar pada alur bisnis.

---

# Minor Version

Digunakan apabila terjadi:

- Penambahan langkah.
- Klarifikasi proses.
- Perbaikan dokumentasi.
