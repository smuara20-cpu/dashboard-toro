# Tujuan

---

# Version Format

Gunakan:

Major.Minor.Patch

Contoh:

1.0.0

1.1.0

1.1.1

2.0.0

---

# Major Version

Perubahan besar terhadap arsitektur atau fitur utama.

---

# Minor Version

Penambahan fitur tanpa breaking change.

---

# Patch Version

Perbaikan bug, optimasi, atau perbaikan dokumentasi.

---

# Changelog

Seluruh perubahan wajib dicatat pada changelog.md.

---

# Deprecated

Komponen lama tidak langsung dihapus.

Status diubah menjadi Deprecated sebelum diganti.

---

# Approval

Flutter Versioning Standard disetujui sebagai standar resmi ERP Travel Intelligence Platform.
