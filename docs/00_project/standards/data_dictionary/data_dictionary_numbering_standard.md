# DATA DICTIONARY NUMBERING STANDARD

Version : 1.0

Status : APPROVED

Document Code : DDS-002

Category : Data Dictionary Standard

Owner : Enterprise Architecture Team

Approval : APPROVED

Last Updated : 2026-08-03

---

# Tujuan

Menentukan standar identifikasi Entity dan Attribute pada Data Dictionary.

---

# Entity Code

Setiap Entity memiliki kode unik.

Contoh:

ENT-COMPANY

ENT-USER

ENT-BOOKING

---

# Attribute Code

Setiap Attribute menggunakan format:

ATTR-001

ATTR-002

ATTR-003

Nomor unik dalam satu Entity.

---

# Compliance

Seluruh Data Dictionary wajib mengikuti standar identifikasi ini.

---

# Approval

Data Dictionary Numbering Standard disetujui sebagai standar resmi ERP Travel Intelligence Platform.
