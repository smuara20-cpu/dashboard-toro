---

# Tujuan

Menentukan proses review Data Dictionary sebelum digunakan sebagai referensi implementasi.

---

# Review Checklist

Reviewer memastikan:

- Seluruh atribut telah didefinisikan.
- Data Type sesuai.
- Constraint sesuai.
- Primary Key benar.
- Foreign Key benar.
- Relationship konsisten.
- Tidak ada atribut duplikat.
- Nama atribut mengikuti standar.
