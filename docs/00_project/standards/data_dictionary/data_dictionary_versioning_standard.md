# Tujuan

Menentukan standar versioning seluruh Data Dictionary.

---

# Format Version

Major.Minor

Contoh:

- 1.0
- 1.1
- 2.0

---

# Major Version

Digunakan apabila terjadi perubahan struktur Entity atau Attribute.

---

# Minor Version

Digunakan apabila terjadi:

- Penambahan atribut.
- Klarifikasi deskripsi.
- Koreksi dokumentasi.

---
