# Tujuan

Folder ini berisi seluruh standar resmi mengenai penyusunan Entity Relationship Diagram (ERD) pada ERP Travel Intelligence Platform.

ERD menjadi acuan utama dalam mendesain struktur relasi antar entitas sebelum implementasi database.

---

Standar ini berlaku untuk seluruh dokumen:

- erd.md

pada seluruh domain ERP Travel Intelligence Platform.
