# ERD NUMBERING STANDARD

Version : 1.0

Status : APPROVED

Document Code : ERDS-002

Category : ERD Standard

Owner : Enterprise Architecture Team

Approval : APPROVED

Last Updated : 2026-08-03

---

# Tujuan

Menentukan standar identifikasi Entity dan Relationship pada ERD.

---

# Entity Code

Gunakan format:

ENT-XXX

Contoh:

ENT-COMPANY

ENT-USER

ENT-BOOKING

---

# Relationship Code

Gunakan format:

REL-001

REL-002

REL-003

---

# Compliance

Seluruh ERD wajib mengikuti standar identifikasi ini.

---

# Approval

ERD Numbering Standard disetujui sebagai standar resmi ERP Travel Intelligence Platform.
