# Tujuan

Menentukan proses review Entity Relationship Diagram sebelum digunakan sebagai acuan implementasi database.

---

# Review Checklist

Reviewer memastikan:

- Seluruh Entity telah didefinisikan.
- Primary Key benar.
- Foreign Key benar.
- Cardinality sesuai.
- Relationship konsisten.
- Tidak terdapat relasi yang duplikat.
- ERD sesuai dengan Data Dictionary.
- ERD sesuai dengan Business Rules.
