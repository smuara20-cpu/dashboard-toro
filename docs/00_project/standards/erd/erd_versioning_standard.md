# Tujuan

Menentukan standar versioning seluruh dokumen ERD.

---

# Format Version

Major.Minor

Contoh:

- 1.0
- 1.1
- 2.0

---

# Major Version

Digunakan apabila terdapat perubahan struktur Entity atau Relationship.

---

# Minor Version

Digunakan apabila terdapat:

- Penambahan Entity.
- Penambahan Relationship.
- Klarifikasi dokumentasi.

---

# Changelog

Seluruh perubahan wajib dicatat pada changelog.md.
