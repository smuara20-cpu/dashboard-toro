Owner : Enterprise Architecture Team

---

# Tujuan

Menentukan standar identifikasi endpoint API.

---

# Endpoint Code

Gunakan format:

API-001

API-002

API-003

---

# Endpoint Naming

Gunakan format:

MODULE-ACTION

Contoh:

BOOKING-CREATE

BOOKING-UPDATE

USER-LOGIN

PAYMENT-CREATE

---

# Compliance

Seluruh API wajib mengikuti standar identifikasi ini.

---

# Approval

API Numbering Standard disetujui sebagai standar resmi ERP Travel Intelligence Platform.
