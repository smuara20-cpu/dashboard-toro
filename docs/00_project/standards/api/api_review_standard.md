---

# Tujuan

Menentukan proses review seluruh API sebelum implementasi.

---

# Review Checklist

Reviewer memastikan:

- Endpoint sesuai Business Rules.
- Validation lengkap.
- Authentication benar.
- Authorization benar.
- Response konsisten.
- Error Code lengkap.
- Dokumentasi lengkap.
- Tidak terdapat endpoint duplikat.

# Reviewer

- Backend Engineer
- Solution Architect
- Enterprise Architect
- Security Architect

- Revision Required
