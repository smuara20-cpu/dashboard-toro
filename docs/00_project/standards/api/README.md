# Tujuan

Folder ini berisi seluruh standar resmi mengenai desain, dokumentasi, implementasi, dan pengelolaan API pada ERP Travel Intelligence Platform.

API menjadi media komunikasi resmi antar Frontend, Backend, Mobile Application, Artificial Intelligence, serta layanan pihak ketiga.

- Internal API
- External API

- Third Party Integration
