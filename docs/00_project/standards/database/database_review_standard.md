---

# Tujuan

Menentukan proses review desain database sebelum implementasi.

---

# Review Checklist

Reviewer memastikan:

- Schema benar.
- Table lengkap.
- Relationship sesuai.
- Constraint sesuai.
- Index sesuai.
- Tidak terdapat redundansi.
- Normalisasi sesuai kebutuhan.
- Konsisten dengan ERD dan Data Dictionary.
