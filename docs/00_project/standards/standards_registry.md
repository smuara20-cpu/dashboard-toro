# Tujuan

Dokumen ini merupakan indeks resmi seluruh standar yang digunakan pada ERP Travel Intelligence Platform.

Seluruh dokumentasi, database, API, source code, AI, UI, dan workflow wajib mengacu pada standar yang terdaftar pada dokumen ini.

# Rules

- Setiap standar wajib memiliki kode unik.
- Setiap standar wajib memiliki Owner.
- Setiap standar wajib memiliki Reviewer.
- Setiap standar wajib memiliki Version.
- Setiap standar wajib memiliki Changelog apabila mengalami perubahan.
- Seluruh dokumen wajib mengacu pada standar yang relevan.
