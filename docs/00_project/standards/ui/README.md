# Tujuan

Folder ini berisi seluruh standar resmi mengenai User Interface (UI) dan User Experience (UX) pada ERP Travel Intelligence Platform.

Standar ini memastikan seluruh tampilan aplikasi memiliki pengalaman pengguna yang konsisten, sederhana, cepat dipahami, dan efisien.

---

# Scope

Standar ini berlaku untuk:

- Mobile
- Tablet
- Desktop
- Dashboard
- AI Interface
