# Governance

Seluruh Architecture Decision baru wajib:

1. Memiliki nomor AD.
2. Melalui Architecture Review.
3. Mendapatkan persetujuan.
4. Dicatat pada Decision Register.
5. Disimpan pada folder `active/`.

Jika suatu keputusan tidak lagi berlaku, dokumen dipindahkan ke folder `deprecated/` dan status pada register diperbarui menjadi **Deprecated**.

# Catatan

Decision Register merupakan indeks resmi seluruh keputusan arsitektur VENTRA dan menjadi bagian dari prinsip Single Source of Truth (SSOT).
