# Purpose of Each Folder

## 00_project

Berisi governance, standar proyek, roadmap, dan aturan engineering.

## 01_architecture

Berisi arsitektur sistem, prinsip desain, dependency, dan keputusan arsitektur.

## 02_business_flow

Berisi alur bisnis setiap domain.

## 03_database

Berisi desain database, ERD, glossary, master data, dan standar data.

## 04_api

Berisi kontrak API, endpoint, versioning, dan integrasi.

## 05_ai

Berisi arsitektur AI, agent, prompt, dan integrasi AI.

## 06_security

Berisi standar keamanan aplikasi dan data.

## 07_decision_log

Berisi seluruh Architecture Decision (AD) dan keputusan penting proyek.

## 08_sprint

Berisi roadmap sprint, milestone, dan delivery plan.

## 09_assets

Berisi aset dokumentasi seperti diagram, ikon, gambar, dan referensi visual.

## 10_domains

Berisi dokumentasi setiap domain bisnis.

## 11_ventra_design_system

Berisi seluruh standar Design System.

## 12_components

Berisi seluruh spesifikasi Component Library.

## 13_flutter

Berisi standar implementasi Flutter.
