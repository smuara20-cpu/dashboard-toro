# PROJECT RULES

Version : 1.0

Status : APPROVED

Last Updated : 2026-08-03

---

# Tujuan

Dokumen ini mendefinisikan seluruh aturan utama (Project Rules) yang wajib diikuti dalam pengembangan ERP Travel AI Platform.

Seluruh anggota tim, AI Assistant, Developer, UI Designer, QA, dan Architect wajib mengikuti aturan pada dokumen ini.

---

# Project Principles

Project dikembangkan berdasarkan prinsip:

- Clean Architecture
- Domain Driven Design (DDD)
- Modular Architecture
- Security by Design
- Documentation First
- API First
- AI Ready
- Multi Company
- Multi Branch
- Multi Tenant

---

# Documentation Rules

Seluruh dokumentasi wajib mengikuti standar resmi yang berada pada:

docs/00_project/standards/

Tidak diperbolehkan membuat format dokumentasi sendiri.
