# ERP TRAVEL AI PLATFORM

# PROJECT CONSTITUTION

Version : 1.0

---

# Tujuan

Dokumen ini merupakan aturan tertinggi (Project Constitution) dalam pengembangan ERP Travel AI Platform.

Seluruh keputusan bisnis, database, API, Flutter, AI, Dashboard, Workflow, dan Security wajib mengacu pada dokumen ini.

Project Constitution berada di atas seluruh dokumen teknis lainnya.

---

# Vision

Membangun ERP Travel AI Platform yang:

- Mudah digunakan
- Membantu operasional perusahaan
- Membantu Tour Leader
- Membantu Jamaah
- Siap digunakan lintas jenis perjalanan
- Mendukung AI
- Siap menjadi SaaS Platform

# Filosofi Produk

ERP bukan sekadar software.

ERP adalah asisten digital yang membantu seluruh aktivitas operasional perusahaan travel.

Semakin sedikit pekerjaan manual yang dilakukan pengguna, semakin baik ERP ini.

---

# Product Vision

Aplikasi harus tetap sederhana walaupun fiturnya sangat banyak.

User tidak boleh merasa sedang menggunakan ERP yang rumit.

User harus merasa sedang dibantu.
