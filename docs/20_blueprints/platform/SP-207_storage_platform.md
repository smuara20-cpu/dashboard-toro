# Purpose

SP-207 Storage Platform mendefinisikan Shared Platform untuk menyediakan capability penyimpanan data dan digital asset secara terpusat, terstandarisasi, aman, scalable, reliable, dapat ditelusuri, dan dapat digunakan oleh seluruh Business Domain VENTRA.

SP-207 menyediakan capability bersama untuk:

- Storage Management
- Storage Repository
- Object Storage
- File Storage
- Storage Metadata
- Storage Namespace
- Storage Classification
- Storage Access Control
- Storage Lifecycle
- Storage Versioning
- Storage Retention
- Storage Archive
- Storage Backup Support
- Storage Recovery Support
- Storage Integrity
- Storage Encryption
- Storage Quota
- Storage Monitoring
- Storage Integration
- Storage Intelligence

SP-207 menjadi foundation bersama untuk penyimpanan digital asset dan storage resource yang digunakan oleh Enterprise.

SP-207 tidak mengambil alih Business Process dari Business Domain.

SP-207 hanya menyediakan capability dan service bersama.

Business Domain tetap menjadi pemilik Business Rule, Business Meaning, dan Business Ownership terhadap data atau digital asset yang mereka kelola.
