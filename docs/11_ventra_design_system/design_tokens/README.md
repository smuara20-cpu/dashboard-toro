# Tujuan

Design Tokens merupakan sumber nilai desain resmi yang digunakan oleh seluruh produk VENTRA.

Semua warna, ukuran, radius, shadow, typography, animation, dan elemen visual lainnya harus mengacu pada dokumen ini.

---

# Prinsip

Design Tokens harus:

- Konsisten
- Reusable
- Mudah dipelihara
- Mudah dikembangkan
- Tidak hardcode di aplikasi

---

# Ruang Lingkup

Design Tokens mencakup:

- Colors
- Typography
- Spacing
- Radius
- Shadow
- Border
- Elevation
- Opacity
- Motion
- Icons
- Z Index

---

# Implementasi

Design Tokens digunakan oleh:

- Mobile Theme
