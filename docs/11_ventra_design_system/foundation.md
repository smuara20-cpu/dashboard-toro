# Tujuan

Foundation merupakan fondasi utama VENTRA Design System yang mendefinisikan elemen-elemen dasar sebelum dibangun menjadi Design Tokens, Components, dan Templates.

Foundation memastikan seluruh produk VENTRA memiliki dasar visual yang konsisten dan mudah dikembangkan.

---

# Scope

Foundation mencakup:

- Layout Foundation
- Grid Foundation
- Color Foundation
- Typography Foundation
- Spacing Foundation
- Radius Foundation
- Elevation Foundation
- Icon Foundation
- Motion Foundation
- Responsive Foundation
- Accessibility Foundation

---

# Foundation Principles

Seluruh Foundation mengikuti prinsip:

- Consistency
- Simplicity
- Scalability
- Reusability
- Accessibility
- Maintainability

---

# Layout Foundation

Layout harus:

- Konsisten di seluruh aplikasi.
- Menggunakan struktur yang mudah dipahami.
- Memiliki hierarki visual yang jelas.
- Mendukung desktop, tablet, dan mobile.

---

# Grid Foundation

Grid digunakan untuk:

- Menjaga konsistensi tata letak.
- Mempermudah alignment.
- Mendukung responsive layout.

Seluruh halaman wajib mengikuti Grid System resmi VENTRA.

---

# Color Foundation

Warna harus:

- Memiliki arti yang konsisten.
- Mendukung keterbacaan.
- Memenuhi standar kontras.
- Tidak digunakan hanya sebagai dekorasi.

Detail warna dijelaskan pada `colors.md`.

---

# Typography Foundation

Tipografi harus:

- Mudah dibaca.
- Konsisten.
- Memiliki hierarki yang jelas.
- Mendukung berbagai ukuran layar.

Detail tipografi dijelaskan pada `typography.md`.

---

# Spacing Foundation

Spacing digunakan untuk:

- Memberikan ruang antar elemen.
- Mengurangi kepadatan visual.
- Membantu pembacaan informasi.

Detail spacing dijelaskan pada `spacing.md`.

---

# Radius Foundation

Radius digunakan untuk menjaga konsistensi bentuk komponen.

Nilai radius dijelaskan pada `radius.md`.

---

# Elevation Foundation

Elevation digunakan untuk menunjukkan hirarki visual.

Penggunaan shadow harus konsisten dan tidak berlebihan.

Detail dijelaskan pada `elevation.md`.

---

# Icon Foundation

Ikon digunakan untuk mempercepat pemahaman pengguna.

Ikon tidak boleh menggantikan informasi penting yang harus ditampilkan dalam bentuk teks.

Detail dijelaskan pada `icons.md`.

---

# Motion Foundation

Motion digunakan untuk:

- Feedback.
- Transition.
- Orientation.

Motion tidak boleh mengganggu produktivitas pengguna.

Detail dijelaskan pada `motion.md`.

---

# Responsive Foundation

Seluruh desain harus mendukung:

- Mobile
- Tablet
- Desktop
- Web

Perubahan layout harus tetap mempertahankan pengalaman pengguna yang konsisten.

---

# Accessibility Foundation

Foundation harus memenuhi prinsip:

- Readability
- Contrast
- Keyboard Navigation
- Screen Reader Compatibility
- Touch Target yang memadai

Detail dijelaskan pada `accessibility.md`.
