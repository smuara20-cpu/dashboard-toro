# Tujuan

VENTRA Design System merupakan standar resmi desain antarmuka yang digunakan pada seluruh produk VENTRA.

Design System ini memastikan seluruh aplikasi memiliki tampilan, perilaku komponen, dan pengalaman pengguna yang konsisten.

---

# Vision

Membangun pengalaman pengguna yang sederhana, konsisten, modern, dan mudah digunakan pada seluruh produk VENTRA.

---

# Scope

Design System ini berlaku untuk:

- ERP Dashboard
- Mobile App

- Desktop App
