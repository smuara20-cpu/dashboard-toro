# Tujuan

Dokumen ini mendefinisikan standar penggunaan ikon pada seluruh produk VENTRA ERP Platform.

Icon System memastikan seluruh ikon memiliki gaya visual, ukuran, makna, dan perilaku yang konsisten di seluruh aplikasi.

Seluruh implementasi ikon wajib mengikuti Design Tokens dan standar Icon System.

---

# Scope

Icon System mencakup:

- Navigation Icons
- Action Icons
- Status Icons
- Notification Icons
- File Type Icons
- Social Icons
- Dashboard Icons
- Custom Icons
- Icon Size
- Icon Color
- Accessibility

---

# Icon Philosophy

Ikon digunakan untuk membantu pengguna memahami fungsi antarmuka dengan lebih cepat.

Ikon berfungsi sebagai pendukung informasi, bukan pengganti informasi utama.

---

# Design Principles

Icon System mengikuti prinsip:

- Consistency
- Clarity
- Simplicity
- Readability
- Scalability
- Accessibility

---

# Icon Categories

Kategori ikon terdiri dari:

- Navigation
- Action
- Status
- Alert
- Dashboard
- Communication
- Media
- Document
- Finance
- Travel

Seluruh kategori menggunakan gaya visual yang sama.

---

# Icon Style

Seluruh ikon harus:

- Menggunakan gaya visual yang konsisten.
- Memiliki proporsi yang seragam.
- Mudah dikenali.
- Tidak menggunakan detail yang berlebihan.

---

# Icon Size

Kategori ukuran ikon:

- Extra Small
- Small
- Medium
- Large
- Extra Large

Nilai ukuran dikelola melalui Design Tokens.

---

# Icon Color

Warna ikon mengikuti Color System.

Ikon tidak boleh menggunakan warna di luar Design Tokens.

---

# Accessibility

Ikon harus:

- Memiliki label apabila digunakan tanpa teks.
- Memiliki kontras yang cukup.
- Tidak menjadi satu-satunya media penyampaian informasi.

---

# Flutter Mapping

Seluruh ikon diimplementasikan melalui Icon Theme dan Design Tokens.

Pemilihan ikon harus konsisten di seluruh aplikasi.

---

# Anti Patterns

Implementasi berikut tidak diperbolehkan:

- Menggunakan ikon dengan gaya visual yang berbeda.
- Menggunakan ukuran ikon hardcoded.
- Menggunakan warna ikon di luar Design Tokens.
- Menggunakan ikon yang sulit dipahami.
- Menggunakan ikon tanpa label apabila diperlukan.
- Mengubah Icon Token tanpa melalui Architecture Review.
