## Tujuan

Data Dictionary adalah referensi utama seluruh struktur database ERP Travel AI.

Semua tabel, kolom, relasi, constraint, dan aturan database harus mengacu pada dokumen ini.

---

## Struktur

Setiap domain memiliki folder sendiri.

- Core
- Customer
- Jamaah
- Booking
- Package
- Finance
- Document
- Hotel
- Ticket
- Visa
- CRM
- Marketing
- Dashboard
- AI
- Notification

## Standar Setiap Tabel

Setiap tabel wajib memiliki informasi berikut:

- Nama tabel
- Tujuan tabel
- Business Rules
- Primary Key
- Foreign Key
- Kolom
- Data Type
- Nullable
- Default Value
- Constraint
- Index
- Audit Fields
- Soft Delete
- Relasi
- Catatan
